# Fun Pay

A reward-based mobile application built with Flutter and Firebase.
Users earn rewards through daily check-ins, ad watching, referrals, and tasks.

## Getting Started

### Prerequisites
- Flutter SDK >=3.5.4
- Firebase project setup

### Installation

```bash
flutter pub get
flutter run
```

### Build

```bash
# Android APK
flutter build apk --release

# Android App Bundle
flutter build appbundle --release

# iOS
flutter build ios --release
```

## Tech Stack

- **Frontend**: Flutter (Material 3, Provider)
- **Backend**: Firebase (Auth, Firestore, FCM, Crashlytics)
- **Ads**: Google AdMob
